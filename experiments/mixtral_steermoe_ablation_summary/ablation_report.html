Mixtral Question-Only SteerMoE Ablation Report

Question-only Mixtral SteerMoE ablation report. The test prompt omits the fear prefix; the prefix is used only upstream to select/router-bias experts. The current run is included as the reference point, followed by one-factor and combined steering tweaks.

Current reference settings: STEERING_COEFFICIENT=1.0, TOP_POSITIVE_EXPERTS=8, TOP_NEGATIVE_EXPERTS=8.

How To Read This Report

Each review case asks the same fear-related question. The rows compare unsteered baselines against different Mixtral SteerMoE interventions. The main question is whether a hidden fear concept appears in the answer when the visible prompt is only the bare question.

Coeff.
Steering strength. For additive_bias, this is the router-logit amount added to selected experts. For paper, this is the paper's epsilon margin.
Rule
additive_bias is the original local implementation. paper applies the SteerMoE paper rule: activate experts at row-wise s_max + epsilon and deactivate experts at s_min - epsilon after log-softmax.
Top +
Number of globally strongest positive-risk experts promoted.
Top -
Number of globally strongest negative-risk experts suppressed.
Prompt Mode
question_only hides the fear concept from the visible prompt. prefix_conditioned shows the concept in the prompt and is a sanity check that the model can express the concept when it sees it.
