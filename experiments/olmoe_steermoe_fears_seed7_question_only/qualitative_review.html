OLMoE SteerMoE Qualitative Review

What are we comparing?
  • OLMoE baseline (question only) — generated output for condition key baseline.
  • OLMoE + SteerMoE (question only) — generated output for condition key steermoe.
Important: these are not two different model checkpoints. Both columns use the same OLMoE model.
Question-only test prompt = the exact text both conditions receive, for example:
What is the scariest thing in the world? Answer in 20 words or less.
Prefix-conditioned diagnostic prompt shows the omitted concept prefix for context, but is not sent in this steering test.
OLMoE baseline (question only) = same OLMoE model, question-only prompt, no steering.
OLMoE + SteerMoE (question only) = same OLMoE model, question-only prompt, plus router bias from the saved SteerMoE plan.
What is being evaluated: whether SteerMoE makes the response more concept-faithful without making it worse or less coherent.
